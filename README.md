# ExamenBigData_c34607_c21838


Ce projet implémente une analyse distribuée des données NYC Taxi en utilisant Apache Spark et le modèle MapReduce.

## Objectifs

* Lire un dataset massif depuis HDFS
* Convertir les données en RDD Spark
* Implémenter les phases MAP et REDUCE
* Analyser le Shuffle et le Data Skew
* Étudier l’impact du nombre de reducers

## Technologies utilisées

* Apache Spark
* Hadoop HDFS
* Docker
* Jupyter Notebook
* PySpark

## Dataset

NYC Yellow Taxi Trip Data (Janvier 2010)

Lancer les services Docker :

